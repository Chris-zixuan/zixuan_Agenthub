## 2. 项目复盘层结构（读用）

> **2026-10-28 起本库不做项目管理。** 用户已删除 obsidian-pm（Project Manager）插件与 `4_项目/` 目录，任务排期、跟催、里程碑改由**外部项目管理软件**承担。
>
> **skill 侧三条硬规则**：
> 1. **不要**在本库创建项目、任务、里程碑、看板或任何待办跟踪物。
> 2. **不要**期待 `pm-project` / `pm-task` / `projectId` 等字段存在——已全库零残留。
> 3. 项目相关内容只有两类：**过程素材**（归档区）与**事后复盘**（复盘区）。

### 2.1 复盘笔记（`3_工作/项目复盘/{项目名}.md`）

- 一篇一项目，**文件名 = 项目名**，不加「复盘」「MOC」后缀。
- 目的：让 `1_日志` 里历史遗留的 `## [[项目名]]` 能直接解析过来。
- `类型: 项目笔记`；**不设 `状态`**（对象已结束，无进度可言）。
- frontmatter：`类型` / `创建时间` / `项目`（列表，与文件名一致） / `客户` / `开始` / `结束` / `总结` / `tags`。
- 正文骨架见 `9_系统/模板/项目复盘模板.md`：
  `# 项目概述` / `# 背景与目标` / `# 方案与实施` / `# 结果与数据` / `# 偏差与根因` / `# 走过的弯路` / `# 可复用结论` / `# 相关素材` / `# 相关日志`

**skill 的边界**：可以补 `总结`、`tags`、建 wikilink、调排版；**不得代填** `客户`、`开始`、`结束`、以及「结果与数据」这类需要当事人回忆或查证的内容——取不到就留空或写「未记录」，**严禁估算与编造**。

### 2.2 归档素材（`3_工作/项目管理/1_归档项目/{项目}/`）

- 已结束项目的**原始素材**：现场记录、会议纪要、方案、SOP，以及存量的 `xxxMOC.md`。
- `类型: 项目笔记`。这里的 `xxxMOC.md` 命名是存量，**不回改**。
- **只读为主**：不新增项目、不写进度、不勾任务。
- 写复盘时**引用**这里的笔记（`- [[文件名]] — 一句话说明`），**禁止把正文复制进复盘**。

### 2.3 入口页

`9_系统/MOC/项目复盘索引.md` —— 列出已建复盘与「有素材但未复盘」的候选，Dataview 动态生成。改项目集合时改这一页的查询，**不要手工维护清单**。

## 3. Dataview 查询模板

> 这些模板不在权威源里，是 skill 执行时用来核对结构 / 查询用的。

### 3.1 复盘 ← 日志关联（精确匹配）

> ⚠️ 两个坑：① `项目` 字段值必须用**精确相等**，不能用 `.includes()`——否则 `长安铸造` 会污染 `长安铸造缺陷检测项目`；② `file.tags` 的值带 `#` 前缀，与裸名比较前要先剥掉。

```dataviewjs
const proj = "项目名";
const pages = dv.pages('"1_日志"')
  .where(p => {
    const items = Array.isArray(p.项目) ? p.项目 : [p.项目];
    if (items.some(v => v && String(v) === proj)) return true;
    return (p.file.outlinks ?? []).some(l => String(l.path).includes(proj));
  })
  .sort(p => p.日期, 'desc');
dv.table(["日期", "项目", "总结"], pages.map(p => [
  p.file.link,
  Array.isArray(p.项目) ? p.项目.join(", ") : (p.项目 ?? "—"),
  p.总结 ?? "—"
]));
```

### 3.2 按标签聚合（剥 `#` 归一化）

```dataviewjs
const TAGS = ["3D视觉", "标定", "缺陷检测"];
const norm = v => String(v).replace(/^#/, "");
for (const t of TAGS) {
  const hit = dv.pages('""')
    .where(p => (p.file.tags ?? []).some(v => {
      const s = norm(v);
      return s === t || s.startsWith(t + "/");
    }));
  dv.header(4, `#${t}（${hit.length}）`);
  dv.list(hit.map(p => p.file.link));
}
```
